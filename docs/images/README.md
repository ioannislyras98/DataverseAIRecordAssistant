# Demo screenshots

The source captures supplied with the MVP are intentionally not committed because they display environment-specific and user-identifying details.

Before adding screenshots here:

1. Use only fictional application data.
2. Crop or redact the Dynamics environment hostname, tenant identifiers, browser profile, and signed-in user details.
3. Redact record GUIDs and any real email addresses.
4. Preserve enough of the interface to show the application form, AI analysis history, and completed recommendation.
5. Export optimized PNG files with these names:
   - `completed-ai-analysis.png`
   - `application-analysis-history.png`

After sanitized images are added, they can be embedded in the root README.
